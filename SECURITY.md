# Security policy

Report vulnerabilities privately through GitHub Security Advisories on this repository
("Report a vulnerability"). Do not open a public issue for a security bug.

Include the crate name and version, the parameter set, and a minimal reproduction. You
will get an acknowledgement, a fix, and credit in the advisory unless you ask otherwise.

## Scope

Every crate in this workspace. Implementation status per algorithm is listed in the
top-level README; nothing here has had a third-party audit yet.
