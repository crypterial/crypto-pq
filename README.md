# crypto-pq

Post-quantum cryptography by [Crypterial Labs](https://crypterial.com): one specification,
written from scratch in Rust, Python, TypeScript, Go and Zig, with no external dependencies.
In development; nothing is usable yet.

| Language | Package |
|---|---|
| Rust | [`crypto-pq`](https://crates.io/crates/crypto-pq) on crates.io (0.1.x was a prototype and is withdrawn) |
| Python | [`crypto-pq`](https://pypi.org/project/crypto-pq/) on PyPI (0.0.x only holds the name) |
| TypeScript | `crypto-pq` on npm |
| Go | `github.com/crypterial/crypto-pq-go` |
| Zig | `github.com/crypterial/crypto-pq-zig` |
